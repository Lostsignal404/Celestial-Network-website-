# Celestial-Network-website-
Website for the server Celestial Network.

This repository contains a lightweight static landing page for the Celestial Network Minecraft community.

Features:
- Discord widget status and member list
- Voice channel overview
- Modal dialogs for widget, appeals, and staff controls
- Theme toggle and mobile navigation improvements

Deployment:
- Host as a static site with GitHub Pages, Netlify, or similar providers.
- Update the Discord widget ID and invites in `index.html` for your community.
